FoNoXid Manager

Your Personal Online Management & Cloud Workspace

FoNoXid Manager is a web-based personal management platform designed to help users organize their digital workspace, manage tasks, store files, and keep important information accessible.

✨ Features

- Cloud File Center – Manage and organize personal files.
- Productivity Center – Create, manage, and track tasks.
- Smart Calendar – Organize events and schedules.
- Notes Manager – Store and manage personal notes.
- Notification Center – Keep track of important notifications.
- Security Center – Access account and security-related tools.
- Cloud Analytics – View available workspace activity and statistics.
- Multi-language Interface – Language selection and localization support.
- Supabase Integration – Authentication, database, and private cloud storage.

🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

🔐 Privacy & Security

FoNoXid Manager uses Supabase authentication and database policies to help keep user data separated and protected.

Private file storage is designed to work with user-specific storage paths and access policies.
